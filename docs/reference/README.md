# Reference shelf

Durable knowledge that is neither intent (that's the spec) nor history (that's the changelog): research briefs worth keeping, integration notes, domain knowledge, competitor landscapes.

- One topic per file, plain English, sources cited.
- **Never loaded by default** — a session opens a reference only when the work touches its topic. That is the whole point of the shelf: knowledge that is available without being a running context cost.
- Fed by promotion: a `docs/brainstorm.md` brief that turns out to be a keeper moves here instead of dying in the archive.
