# Project Spec — Swiss discovery-and-build run

## What Is This Product?

Not yet selected — by design. This is a bounded, autonomous discovery-and-build run: find one real, underserved problem affecting many ordinary people in Switzerland, prove that public reusable data and a sub-EUR-5/month architecture can serve it, then build a bilingual web application for one precise audience. If no candidate passes the evidence gates, the approved outcome is a well-supported **NO-GO** with the research delivered.

## Selection standard (the hard gates)

A candidate is selected only if **all** hold; a high aggregate score never cancels a failed gate:

1. **Not excluded:** no railway or noise-related products.
2. **Real job, real gap:** a specific user, recurring situation, concrete loss; closest alternatives named with the precise remaining gap. An existing tool that solves the same task well for the same people rejects the candidate unless a material advantage is demonstrated.
3. **Data proven, not assumed:** every essential source is publicly accessible, **reusable under stated terms (attribution and commercial-use restrictions recorded)**, fresh enough, and actually downloaded, parsed, and joined in a sample before selection.
4. **Budget:** all-in recurring cost below EUR 5/month with margin.
5. **Buildable tonight:** one coherent end-to-end journey verifiable locally.

## Engineering Profile

- **Exposure:** public web application (not deployed this run)
- **Sign-in:** none
- **Data:** public open data only
- **Money moves:** no
- **External integrations:** Swiss public data sources (read-only)
- **Loss tolerance:** a user must never see fabricated figures
- **Regulated:** no
- **Proof command:** none yet
