# House Rules

The owner's non-negotiables for this discovery-and-build run. Contact with one of these is a STOP for the night shift.

**Budget ceiling:** total recurring operating cost below EUR 5 per month, all-in, with margin. Never assume free allowances exist.

**Never without the owner:** deploy, provision infrastructure, purchase anything, merge into the default branch, contact people, publish anything.

**Data:** only publicly accessible, reusable data with recorded reuse terms and attribution. Preserve provenance. A failed refresh never replaces last-known-good data.

**Honesty in reporting:** every figure is reproducible by a stated command or labelled an estimate. Failed checks stay visible after repair.
